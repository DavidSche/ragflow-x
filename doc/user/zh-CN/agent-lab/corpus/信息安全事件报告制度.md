# 信息安全事件报告制度（练习语料）

> 本文件是《智能体上手指南》练习包的语料，内容为虚构示例，仅用于验证检索与引用能力。

## 第一章 事件分级

**第一条** 信息安全事件按影响范围分为四级：

| 级别 | 判定标准 |
| --- | --- |
| 特别重大 | 核心业务系统中断，或敏感数据被批量泄露 |
| 重大 | 部门级系统中断，或单个业务库被非授权访问 |
| 较大 | 员工账号被盗用、终端感染勒索软件但已隔离 |
| 一般 | 钓鱼邮件被点击但未造成损失、弱口令被扫描发现 |

**第二条** 级别由信息安全部确认，现场人员不得自行降级。

## 第二章 报告时限

**第三条** 发现事件后按下表时限上报，超时视为隐瞒：

| 级别 | 上报时限 |
| --- | --- |
| 特别重大 | 30 分钟内 |
| 重大 | 2 小时内 |
| 较大 | 24 小时内 |
| 一般 | 3 个工作日内 |

即：特别重大的 30 分钟内上报，重大的 2 小时内上报，较大的 24 小时内上报，一般的 3 个工作日内上报。时限从「发现事件」起算，不以「确认级别」起算；级别未定的先按高一级时限上报。

**第四条** 上报对象为信息安全部值班电话与事件单系统，两者都要留痕；只打电话不建单视为未上报。

**第五条** 上报内容须包含：发现时间、影响系统、现象描述、已采取的措施、发现人联系方式。

## 第三章 现场处置

**第六条** 处置顺序固定为：先止损（断网、隔离主机）、再取证（保留日志与内存镜像）、后恢复。

**第七条** 处置期间禁止以下行为：自行删除数据、重装系统、格式化磁盘、清除日志。

**第八条** 涉及客户数据的，由信息安全部统一对外沟通，其他人员不得自行通知客户或媒体。

## 第四章 复盘与归档

**第九条** 事件关闭后 **5 个工作日** 内提交复盘报告，内容包括根因、影响、整改项与责任人。

**第十条** 整改项须在复盘报告批准后 30 日内完成，未完成的由信息安全部上报管理层。

**第十一条** 事件记录与复盘报告至少保存三年，供内外部审计调阅。
